
# 크롬북에서 vim 분할창 이동 단축키 변경 

vi에서 분할 창 이동 단축 키 : Ctrl + W
크롬북에서 창 받기 : Ctrl + W

Ctrl + W 중복이라 집에서 vi 사용중에 습관적으로 분할창 이동하려고 할 때 
창이 닫혀 버리는 경우가 많아 아래와 같이 .vimrc를 수정하기로 함.
(습관이 굳어져서 쉽게 바꾸기는 어려울 듯..)


```
" Ctrl+w 관련 단축키 비활성화 (선택 사항)
nnoremap <C-w> <Nop>
nnoremap <C-w><C-w> <Nop>

" 새로운 창 이동 단축키 설정 (Ctrl + 방향키)
nnoremap <C-Left>  <C-w>h
nnoremap <C-Down>  <C-w>j
nnoremap <C-Up>    <C-w>k
nnoremap <C-Right> <C-w>l

nnoremap <C-h>  <C-w>h
nnoremap <C-j>  <C-w>j
nnoremap <C-k>    <C-w>k
nnoremap <C-l> <C-w>l

```
